# Integrated Intelligent Systems (IIS)

Coursework and practical assignments for the **M.Sc. Artificial Intelligence and Intelligent Systems** programme at the **University of Bremen** (Winter Semester 2026/27).

This repository contains tutorial solutions, Python implementations, and exercises completed as part of the IIS course.

**Topics:** Intelligent Systems, Robot Architecture, Perception, Planning, and Execution.

**Tools:** Python, Jupyter Notebook, Git, and VS Code.
